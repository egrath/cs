## Project
Faithful console clone of MicroPro/Sorcim CalcStar (1981) spreadsheet.
- Language/build: pure C89 (-std=c89 -pedantic -Wall), ncurses (-lcurses -lm), plain Makefile in project root. Build target: ./calcstar. `./calcstar --test` = headless regression suite.
- Authoritative screen reference: /Users/egon/tmp/cs1.txt (80x24 genuine capture; B3 = 33 shown as "33.00").
- No git repo. Files under src/: main.c screen.c command.c cells.c eval.c parser.c fileio.c print.c help.c cs.h + Makefile + README.md.

## BATCH 7 (previous): BCD engine replaces floating point; files list now also has num.c/num.h:
- num.c/num.h: value = 0.d1..dn * 10^exp, CSN_DIGS=18 (14 calc + 4 guard),
  CSN_EMAX=999. finish() canonicalizes (leading-zero skip, trailing-zero
  strip, mantissa cut, range check; E>999 -> overflow, E<-999 -> zero).
- mag_add: digits over window lo..hi+1 with carry (NO lo extension below the
  window - operand digits always fit [hi-17..hi]; extending overflowed the
  stack -> SIGABRT). mag_sub models below-window borrows with borrow0 flag.
- mul: LSB-first digit arrays res[i+j] + carry pass; E_out = Ea+Eb-na-nb.
  div: streaming long division (rem < 10^(nb+1)); quotient digit j at place
  (na-j) of ma_int/mb_int; value factor 10^(Ea-Eb-ndig_a+ndig_b); the
  rem>=den compare must return TRUE on equality (caused q=1.9999 bug).
- sqrt: Newton + snap to the largest 15-digit y with y*y <= x.
  exp: reduce by whole ln10 (subtract while x > ln10/2), Taylor series;
  term-stop must compare |term| (signed compare broke EXP(-20) at 1e-8).
  ln: m = x*10^(1-E) in [1,10); one sqrt(10) half-step adds only LN10H
  (k+=1 bug doubled ln(9.99)). log10 DIRECT = (E-1) + log10(m) -> powers
  of ten exact (LOG(0.001) = -3).
- csn_parse returns CSN_OK(0)/CSN_ER_SYNTAX(4)/CSN_ER_OVERFLOW(1) (syntax
  used to collide with OK=0 -> parser err 8 everywhere).
- csn_fmt_sci: displayed exponent = exp10-1 (manual's 7.35E-6 example).
  cs_fmt_num(const Csn*, ...) fixed->sci->"*" overflow fallback.
- Cell.val Csn; parser Val.num Csn; cs_eval_formula(s, Csn*, char**); 
  g_reg_* Csn + cs_reg_reset(); cs_set_num takes const Csn*; print/screen
  format call sites pass &c->val.
- Save format CSD2: BCD record = sign byte, exp10 LE i16, ndig byte, 18
  digit bytes; CSD1 refused with "READ ERROR" (verified interactively).
- main.c --test: exact decimal strings via canon form; save/load + old-file
  refusal checks; cs_headless guards cs_msg under --test (no curses).
- Differential battery vs python-decimal at 14 digits: SQRT/EXP(-20)/LN/LOG
  incl. LN(9.99), EXP(0.001), LOG(0.123) all match; --test + cs1.txt idle
  EXACT; build warning-free with NO math.h/double/float anywhere in code.
- HARNESS: canon string convention is digits-as-0.d1d2.. * 10^E (E printed
  as given); note the sci display form uses exp10-1. Bugs historically came
  from mixing those two conventions when writing test wants.
